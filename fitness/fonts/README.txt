Optional: the exact Solo Leveling title font.

The Solo Leveling logo lettering is custom artwork. The closest published font is "Eternal" by FG Studios,
which is free for personal use only, so it cannot be bundled in a public repository.

If you own a copy you are allowed to use, put it in this folder named exactly:
    solo-leveling.woff2   (or solo-leveling.ttf / solo-leveling.otf)
LEVEL//UP then uses it for titles automatically. Without it, titles use Orbitron and text uses Rajdhani.
